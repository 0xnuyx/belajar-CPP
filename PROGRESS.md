## Status Legend

Pilih satu status yang paling menggambarkan kondisi tiap bab.

- `⬜ Not started` — belum dipelajari.
- `📖 Reading` — sedang membaca dan mengumpulkan pertanyaan.
- `📝 Notes complete` — sudah menulis ringkasan dengan kata-kata sendiri.
- `🧪 Practiced` — sudah mencoba contoh kode atau mengerjakan latihan.
- `✅ Reviewed` — bisa menjelaskan ide utamanya tanpa melihat catatan dan sudah tahu bagian yang masih perlu diulang.

Kolom **Confidence** adalah penilaian pribadi dari 1 sampai 5, bukan nilai ujian. Isi setelah belajar, bukan sebelum mulai.

# Modern C++ Progress

Bagian ini melengkapi buku. Nggak perlu menuntaskan semua fitur sekaligus. Centang topik setelah paham tujuan dan perilakunya, lalu coba contoh kecil bila relevan.

## C++11 — Foundation and book baseline

- [ ] `auto`, `nullptr`, dan uniform initialization
- [ ] `enum class` dan range-based `for`
- [ ] Lambda expressions
- [ ] Move semantics dan rvalue references
- [ ] Smart pointers: `unique_ptr`, `shared_ptr`, `weak_ptr`
- [ ] `constexpr` dan `noexcept`
- [ ] Dasar concurrency: thread, mutex, future/promise

**Practice:** buat contoh kecil yang menunjukkan kegunaan beberapa fitur C++11, bukan cuma menghafal syntax.

## C++14 — Small improvements

- [ ] Generic lambda
- [ ] Perbaikan `constexpr`
- [ ] `std::make_unique`
- [ ] Binary literals dan digit separators

**Practice:** bandingkan contoh C++11 dan C++14 untuk melihat apakah versi baru membuat kode lebih sederhana.

## C++17 — Everyday modern C++

- [ ] Structured bindings
- [ ] `if`/`switch` initializer
- [ ] `if constexpr` dan fold expressions
- [ ] `std::optional`, `std::variant`, dan `std::any`
- [ ] `std::string_view`
- [ ] `std::filesystem`

**Practice:** coba gunakan `optional` atau `variant` pada program kecil, lalu catat kapan keduanya lebih cocok daripada pendekatan lain.

## C++20 — Main modernization target

- [ ] Concepts dan `requires`
- [ ] Ranges, views, dan ranges algorithms
- [ ] `std::span`
- [ ] `std::jthread` dan stop tokens
- [ ] `consteval` dan `constinit`
- [ ] Three-way comparison (`<=>`)
- [ ] Dasar modules dan dukungan toolchain
- [ ] Dasar coroutines — topik lanjutan
- [ ] `std::format` — cek dukungan library yang dipakai

**Practice:** pilih satu contoh yang relevan dari buku, buat versi C++20, lalu bandingkan readability, safety, dan trade-off-nya.

## C++23 — Modern follow-up

- [ ] `std::expected`
- [ ] `std::print` / `std::println` — jika didukung library
- [ ] `std::mdspan`
- [ ] Peningkatan ranges yang relevan
- [ ] Fitur terpilih lain setelah fondasi C++20 cukup kuat

**Practice:** pilih satu fitur yang menyelesaikan kebutuhan nyata. Nggak harus mencoba semuanya sekaligus.

## C++26 — Exploration only

- [ ] Cek status fitur dari sumber resmi
- [ ] Bedakan proposal, draft, dan fitur yang sudah final
- [ ] Cek dukungan compiler serta standard library sebelum bereksperimen
- [ ] Simpan contoh C++26 terpisah dari contoh utama

C++26 bukan syarat untuk menyelesaikan roadmap. Anggap bagian ini sebagai eksplorasi saat dukungannya sudah memadai.
